## 4. Run ID 与清理机制

- [x] 4.1 实现每次运行生成唯一 `runId`，并在所有测试可命名资源中使用 `e2e_` 前缀。
- [x] 4.2 实现 cleanup registry，记录本次创建的用户、项目、源码、导入、凭据、环境、任务、上传文件和队列信息。

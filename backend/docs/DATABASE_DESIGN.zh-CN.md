# 后端数据库说明

[English](DATABASE_DESIGN.md) | 简体中文

数据库使用 PostgreSQL，结构以 `src/main/resources/db/changelog/db.changelog-master.yaml` 及其引用的 SQL 为准。Liquibase 管理变更顺序；jOOQ 类型由已初始化的数据库生成。历史设计记录保留在后端 OpenSpec 中。

## 主要数据领域

| 领域 | 主要数据 |
|---|---|
| 账户和访问 | 用户、邀请与重置令牌、系统配置、审计日志 |
| 项目和源码 | 项目、源码版本、导入、部署和项目运行环境绑定 |
| 环境和凭据 | 加密凭据、环境、环境快照、环境组件 |
| 任务与 worker | 任务、事件、日志、运行句柄和 worker 心跳 |
| 迁移分析 | KB 扫描及发现、构建驱动依赖分析、依赖修复、浮点和内存序专项分析 |
| 迁移输入与问题 | 输入集、来源引用、问题与问题事件 |
| 模型和 agent | 模型配置、阶段分配、agent runtime 和探测记录 |
| 构建与验证 | 构建运行、自动化测试、测试比较与差异 |
| 报告与制品 | 报告、报告输入、对象存储制品、归档候选和归档项 |

## 数据与执行边界

PostgreSQL 保存任务和业务结果的权威状态。RabbitMQ 投递任务标识，worker 从数据库读取输入；对象存储保存输出制品，数据库记录其所有者和位置。日志与凭据处理须遵守对应服务中的访问及脱敏规则。

凭据在写入数据库前通过部署提供的主密钥加密。主密钥不写入源码、数据库迁移或测试报告。数据库默认管理员的初始化规则见安装指南；不得将开发默认口令作为部署凭据。

## 初始化与生成代码

首次部署使用空数据库初始化，外键、约束和索引由 Liquibase 变更链创建。已有部署升级前应单独验证 changeset 校验和及数据兼容性。

所有数据库迁移验证和 jOOQ 生成在 Docker 中执行，使用独立容器、网络和数据库，不能对现有运行库操作。步骤见 [开发指南](../../docs/开发指南.md)。

生成类型保存在 `src/generated/java/`。修改 schema 后重新生成，不能以手工修改类型代替初始化和生成验证。

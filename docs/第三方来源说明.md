| 材料 | 来源与声明 | 使用与声明 |
|---|---|---|

| AVX 扫描报告中的源码片段 | [Triple-Z/AVX-AVX2-Example-Code](https://github.com/Triple-Z/AVX-AVX2-Example-Code)，上游声明 BSD-3-Clause | 保留报告中的作者署名；补齐 [AVX-LICENSE](../tools/kb-scanner/tests/fixtures/source-evidence-chain/AVX-LICENSE)，未修改原报告内容、ID 或摘要 |
| 浮点测试的四个 LLVM bitcode 文件 | 同目录 C 源码、生成命令与 SHA-256 表，见 [夹具说明](../tools/floating-point-precision-scanner/tests/fixtures/bitcode/README.md) | 保留必要固定输入；Docker llvm-dis 核对仅包含 `/workspace` 与相对路径，无内部工作目录 |
| 内存序分析器中的旧工具最小回归夹具 | 各夹具目录的 `provenance.json`、`sample-inventory.json` 记录原路径、摘要和改写原因 | 保留来源证据，其中原许可未声明的材料仍须维护者确认授权 |
| 前端六个 SVG、一个 AVIF 和 favicon | 前端交付基线中的正式产品资源 | 标志渲染后显示 RvPort；SVG 内嵌位图与 AVIF 均为抽象背景，favicon 为无文字图标，无账号或环境截图。AVIF 无元数据，ICO 仅含尺寸信息；资源授权仍由维护者确认 |

邮箱扫描中的 GNU、libarchive、AVX 作者联系信息来自上述公开材料；这些署名不作为内部环境信息替换。`git@github.com` 是 SSH URL 语法；示例邮箱使用 example 域或测试专用域。扫描记录只保存文件位置和域名，不复制邮箱原值。

## 在 Docker 内下载的依赖

MinIO 从固定官方提交构建，归档 SHA-256、上游地址、AGPL 声明位置和构建方式见 [对象存储说明](../infra/minio/README.zh-CN.md)。上游 LICENSE 与 NOTICE 随运行镜像保存，不将其许可误写为 RvPort 自有代码的许可。

LLVM、JDK、Node.js、npm/Python/Maven 依赖继续使用各自的上游发布与锁定版本；不把下载的源码、包缓存和镜像导出带入新仓库，也不移除第三方包自带的许可声明。

RISC-V 迁移工具面向 RISC-V 平台，帮助开发者将既有软件资产平滑迁移到 RISC-V 架构。


### 工具简介

面向**源代码级**的迁移辅助工具。支持扫描 x86/ARM 代码库，自动识别待迁移点（含汇编、intrinsic、内置函数、ABI 调用约定等），结合知识库给出迁移建议，并支持 AI 生成、diff 视图、依赖库扫描等能力。

- **典型场景**：将既有 x86/ARM 应用移植到 RISC-V 架构。

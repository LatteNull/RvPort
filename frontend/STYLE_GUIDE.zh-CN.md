# 前端样式规范

[English](STYLE_GUIDE.md) | 简体中文

适用于项目首页、管理页、个人设置、Workflow/Step 的阶段内容以及共享弹层。优先沿用现有组件，不因统一样式改变业务流程。

## 字体层级

数值只在 `src/theme.ts` 定义，组件使用 Ant Design 官方 CSS 变量。`src/styles/mixins.scss` 提供对应的语义 mixin；不要创建另一套主题变量。

| 用途                             | 字号 / 字重 / 行高 | 使用方式             |
| -------------------------------- | ------------------ | -------------------- |
| 页面主标题                       | 20px / 500 / 28px  | `type.page-title`    |
| 弹窗、抽屉、Step 详情标题        | 18px / 500 / 24px  | `type.panel-title`   |
| 内容区域标题                     | 16px / 500 / 24px  | `type.section-title` |
| 正文、表单、常规操作             | 14px / 400 / 22px  | `type.body-text`     |
| 辅助说明、标签、时间、状态元信息 | 12px / 400 / 20px  | `type.helper-text`   |

- 常规字重使用 400、500、600。600 用于需要强调的结论或数值，不用于所有标题。
- 密集列表、路径和日志可以使用 13px / 20px；源码工作区的次级标题保留 15px / 500 / 22px，文件路径为 13px / 400 / 20px。不要把内部信息提升为页面标题。
- 数值摘要可以使用 20px 或 24px，不再引入 21px、22px、26px 等相近档位。
- 普通页面文字不使用 10–11px。Workflow 画布标记允许 11px，因为它随整个画布缩放；图标大小独立于文字层级。
- Monaco 的字号由编辑器选项管理，保留 14px；文本路径、日志和代码片段使用 `--ant-font-family-code`，其余继承系统字体。
- BaseModal、BaseDrawer 同时覆盖字符串标题与标题对象；StagePanel 使用相同标题规格。业务自定义标题应复用公共标题，不再增加局部字号覆盖。

```scss
@use '../../styles/mixins' as type;

.title {
  @include type.page-title;
  color: var(--ant-color-text);
}
```

## 间距与视觉层级

同类内容按下表选择相同间距，避免相邻页面出现 20 / 22 / 28px 等近似值。

| 对应关系                            | 默认间距  |
| ----------------------------------- | --------- |
| 独立内容大区块之间                  | 24px      |
| 同一区域内部的内容分组、左右内容列  | 16px      |
| 标题与紧随的说明文字                | 4px       |
| 紧凑列表标题与列表、列表项之间      | 12px      |
| 同组操作按钮、筛选控件之间          | 8px       |
| 执行记录条、紧凑摘要/列表卡片内边距 | 12px 16px |
| 独立结论/建议内容容器内边距         | 16px      |

- 页面标题到正文默认 16px；带分隔线的管理页标题区与正文各保留 24px。源码、列表等真正的容器边界两侧可以分别保留内边距。
- 大面积留白可以使用 32 / 48px；两行紧凑元信息可以使用 2 / 4px，不能把它当成独立区域标题与正文的距离。
- 行内图标间距、画布坐标、编辑器尺寸和紧凑导航可以按组件用途单独设定，避免为了凑整数改变布局。
- 弹层标题区为 `12px 24px`，操作区为 `16px 24px`；Modal 正文为 24px，Drawer 正文为 `16px 24px`。嵌入式 StagePanel 保持紧凑内边距。
- 主文字使用 `--ant-color-text`，说明使用 `--ant-color-text-secondary`，非必要元信息使用 `--ant-color-text-tertiary`。风险、运行中、成功等颜色遵循现有语义。
- 用字号、字重、留白建立层级；容器优先柔和底色。源码组合工作区只保留一层真实边界，不添加嵌套卡片装饰。

## 本次巡检与修正

| 问题                                                                                     | 修正                                                       |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 管理页标题 28px，首页及个人设置 20px；管理中心标题又使用 24px                            | 页面标题统一为 20px / 500 / 28px                           |
| BaseDrawer 对象标题 20px，BaseModal 18px / 600，StepPanel 16px；字符串标题依赖组件默认值 | 公共容器统一为 18px / 500 / 24px，覆盖字符串和对象两种标题 |
| 同级阶段标题有 600 字重或继承浏览器粗体，行高不统一                                      | 16px 区域标题使用公共 mixin；保留工作区内部的次级层级      |
| 状态说明、版本号、分析元信息有大量 10–11px 小字                                          | 普通文字提高到 12px；保留小图标和画布标记                  |
| 使用 550 / 620 / 650 字重及相近的统计字号                                                | 收敛为标准字重与 20 / 24px 统计字号                        |
| 重复硬编码中性色、等宽字体和常规字号                                                     | 使用现有 Ant Design 官方变量                               |
| 首页、管理页和弹层对应区域的间距不一致                                                   | 收敛对应标题、列表及弹层间距；保留布局所需尺寸             |

补充修正：评估报告的大区块 28 / 20px 收敛为 24px，优化阶段 22 / 28px 收敛为 24px；知识库、依赖分析及报告同类记录条的 13 / 14px 上下内边距收敛为 12px。构建、测试、归档标题与说明采用 4px，创建项目和阶段操作区按钮采用 8px。

## 容器与状态展示

- 常规输入与按钮圆角为 4px，小型记录、提示、内部内容容器为 8px，主要工作区、弹层和首页项目卡片为 12px。8px 使用基础圆角的两倍，12px 使用 `--ant-border-radius-lg`；圆形图标、胶囊标签和流程画布形状保留用途尺寸。
- 普通分组使用 `--ant-color-fill-quaternary`，交互 hover 使用 `--ant-color-fill-tertiary`；源码、日志和表格区域保留真实边界。风险与前置条件使用官方语义色。
- 页面内容卡片使用留白、底色和必要边界；阴影保留给弹层和真正的悬浮层。
- 数据为空、筛选无结果、请求失败和无固定结构的加载使用 `ContentState`。独立区域最小高度 240px，嵌入区域使用 `compact`（160px）；说明、图形和操作沿用同一布局。
- 失败使用 `kind="error"`，筛选无结果使用 `kind="filtered"`，加载使用 `kind="loading"`。错误与空数据保持不同语义，重试回调由原调用方提供。
- 已知布局的首次加载继续使用 `StageViewLoading` 骨架；行内 AI 建议状态等局部请求使用小型 Spin。阶段前置条件、执行进度与执行失败使用 `StageStateNotice` 保留业务事实，字号与间距遵循共同规则。

## 操作与交互反馈

- 每个区域保留一个主操作（primary）；返回、取消、清空筛选使用 default，历史入口和辅助导航使用 link/text，危险操作保留 danger 与已有确认流程。
- 页面/区域请求失败的重试使用标准主按钮；统一去掉默认按钮阴影。业务禁用、loading 和 busy 行为由现有逻辑控制。
- 原生可点击元素提供 2px 主色 `:focus-visible` 轮廓与 2px 偏移；普通 hover 使用底色/颜色反馈，避免卡片位移。
- 交互颜色过渡使用 `--ant-motion-duration-mid`（200ms），弹层等动画使用官方对应时长。开启 `prefers-reduced-motion` 后停止重复装饰动画并缩短过渡，保留操作及状态信息。

已补齐新建项目弹窗的局部标题覆盖。共享状态组件用于首页、管理详情、阶段结果、执行记录、日志及报告空态，并与 BaseTable 和 StageViewLoading 的普通加载模式复用。

## 验收

- 检查页面、区域、列表项、证据工作区四层信息权重，避免所有文字同样粗大。
- 在 1280 / 1440 / 1920 三档桌面宽度检查换行、长路径、按钮、滚动容器及弹层；重点关注提高辅助字号后的项目上下文条。
- 保持键盘焦点、对比度和减少动画设置；视觉验收与格式、类型、测试、构建检查分别记录。

## Context

当前固定布局使用 React Flow，源节点与汇合点间的有效水平距离可能小于默认两端偏移之和。回流线各自根据端点计算通道，标签固定居中。日志接口从文件尾分页，但每页内部保持时间正序。

## Goals / Non-Goals

目标：消除窄间距折返、避免标签与回流竖线重叠、恢复日志自然阅读顺序。
非目标：自动布局、节点拖拽路由、业务拓扑调整、后端修改。

## Decisions

- 从右到左且目标位于右侧的连线，将 offset 限制为水平间距的一半，保留原有圆角及交互路径。
- 从拓扑计算分组底部，以 40px 间距分配两条回流通道；标签位于靠近起点的无竖线交叉区间，并用背景色描边留白。
- 保留分页数组反转，移除单页字符串行反转。历史页向前拼接，实时增量逻辑保持原有行为。

## Risks / Trade-offs

回流通道占用更多画布底部空间，浏览器需检查整体与放大视图。路由基于固定拓扑，若未来允许节点拖拽，应改为从实时节点坐标计算。

## Validation

覆盖窄间距路由、通道间距、标签避让、最新单页与跨页日志顺序。执行前端格式、lint、类型检查、测试及 OpenSpec 验证，并检查浏览器实际显示。

## 全量验收修正

动画测试不再依赖已移除的逐节点 Sass 变量，改为检查编译后 CSS 的媒体规则、动画作用选择器及媒体规则外无动画；所有阶段的边高亮仍由 model.test.ts 覆盖。源码导入测试保留可见性和拒绝提交断言，用 waitFor 等待动画结束。评估报告入口只做 Prettier 格式调整。

## 方案

`src/theme.ts` 是字号和行高的唯一主题入口。使用 Ant Design 官方 CSS 变量，公共 mixin 表达页面、弹层、区域、正文和辅助信息角色；组件无需另建主题系统。

页面标题采用 20/500/28，弹层及详情标题采用 18/500/24，区域标题采用 16/500/24，正文采用 14/400/22，辅助信息采用 12/400/20。代码工作区次级标题、密集路径、数值和可缩放画布按 STYLE_GUIDE 的例外处理。

BaseDrawer 与 BaseModal 的 semantic title slot 统一字符串标题，CSS Module 统一标题对象，StagePanel 及记录详情标题使用同一规格。只调整对应信息层级及公共间距，保留阶段内容组织、编辑器尺寸和交互行为。

## 风险与验证

辅助字号提高可能使紧凑项目上下文或长路径提前截断。通过三档桌面宽度、真实认证页面及弹层验收，必要时保留省略和换行行为。主题和样式变化通过类型检查、现有测试、lint、格式、构建和 OpenSpec 校验验证。
